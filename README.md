# 🏓 Pong Game – Jogo Clássico em Python

Este projeto é uma recriação do clássico **jogo Pong**, desenvolvido em **Python** com a biblioteca **Pygame**. O objetivo é proporcionar uma experiência divertida para dois jogadores em um mesmo teclado.

---

## 🎮 Descrição do Projeto

O jogo simula uma partida de tênis de mesa com duas raquetes e uma bola que se move entre elas. Cada jogador controla uma raquete e tenta impedir que a bola ultrapasse sua área. A pontuação é contabilizada automaticamente a cada ponto marcado.

### Principais Funcionalidades:

- **Modo para Dois Jogadores** no mesmo teclado.
- **Contagem de Pontos** para ambos os jogadores.
- **Controles de Teclado** simples e responsivos.
- **Interface Gráfica Interativa**, desenvolvida com `pygame`.

---

## 🛠️ Tecnologias Utilizadas

**Linguagem de Programação:**
- Python

**Bibliotecas:**
- `pygame` – Responsável por toda a interface gráfica e lógica do jogo.
